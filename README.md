# Моя Вселенная

Личная 3D-карта жизни: галактики = сферы жизни, звёзды = достижения, навыки,
цели, обучение и то, что не получилось. Всё зашифровано на вашем устройстве —
пароль нигде не хранится.

**Приватная версия (Cloudflare Pages, закрыта паролем хостинга):**
https://my-universe-6i8.pages.dev/

Публичная версия без пароля хостинга (только пароль приложения):
https://surelybusinessman.github.io/my-universe/

## Два разных пароля

На Cloudflare-версии сайт защищён **двумя независимыми паролями**:

1. **Пароль хостинга** — обычный HTTP Basic Auth (логин/пароль), который
   спрашивает сам браузер ещё до того, как загрузится страница. Задаётся в
   Cloudflare Pages → Settings → Variables and secrets → `SITE_PASSWORD`.
   Логин может быть любым, важен только пароль.
2. **Пароль приложения** — тот, что вы придумываете при первом входе во
   вселенную. Им шифруются сами данные (AES-256-GCM).

Забыли пароль хостинга — поменяйте `SITE_PASSWORD` в настройках Cloudflare
Pages и передеплойте (Deployments → Retry deployment). Забыли пароль
приложения — используйте код восстановления, см. ниже.

## Безопасность и бэкапы

- Пароль защищает вход, а сами данные дополнительно зашифрованы (AES-256-GCM).
  Даже если кто-то откроет ссылку, без пароля содержимое — нечитаемый набор байт.
- При первом создании вселенной вы получаете **код восстановления** — это
  единственный способ вернуть доступ, если забудете пароль. Он нигде не
  хранится и не восстанавливается нами. Держите его в отдельном надёжном
  месте (менеджер паролей, бумага, сейф) — не в этом же браузере.
- Все данные хранятся в IndexedDB вашего браузера, привязаны к конкретному
  браузеру и устройству. **Периодически делайте резервную копию:**
  - Откройте DevTools → Application → IndexedDB → `my-universe`, либо
  - Проще: заведите привычку раз в 1-2 недели заходить и держать пароль/код
    восстановления под рукой — сам факт входа подтверждает, что данные живы.
- Если планируете чистить историю браузера, куки или "данные сайтов" —
  сначала выгрузите бэкап, иначе вселенная будет удалена вместе с этим.
- Перенос на другое устройство: см. `перенос/ПРОЧТИ-МЕНЯ.md` — файл копии
  переносится вручную, либо (если включена синхронизация, см. ниже)
  подтягивается автоматически при входе по паролю.

## Синхронизация между устройствами (опционально)

При входе приложение пытается забрать более свежую версию с сервера, а после
каждой правки — отправить свою. Сервер хранит ровно тот же зашифрованный
контейнер, что лежит в IndexedDB и что скачивает кнопка «Копия»: пароль,
masterKey и расшифрованные данные на сервер никогда не попадают.

Работает только на Cloudflare Pages (GitHub Pages не исполняет функции) и
только после ручной настройки:

1. Создайте KV namespace: Cloudflare Dashboard → Workers & Pages → KV → Create.
2. Привяжите его к проекту: Pages-проект → Settings → Functions →
   KV namespace bindings → добавьте binding с именем **`VAULT_KV`**.
3. Передеплойте (Deployments → Retry deployment).

Без этой настройки `functions/api/vault.js` отвечает `501`, и приложение молча
работает как раньше — без синхронизации, ошибок пользователь не увидит.

Если один и тот же интервал времени отредактирован на двух устройствах
одновременно (например, оба были офлайн), автослияние невозможно — сервер
видит только шифротекст. Приложение покажет выбор: оставить эту версию или
взять версию с другого устройства.

## Разработка

```bash
npm install
npm run dev      # локальный запуск
npm run build    # прод-сборка в dist/
```

## Деплой

Автоматический на оба хостинга: любой push в ветку `main` запускает сборку.

- **GitHub Pages** — через `.github/workflows/deploy.yml`, путь `/my-universe/`.
- **Cloudflare Pages** — подключён напрямую к репозиторию через дашборд
  Cloudflare (Workers & Pages → my-universe), путь `/`. Дополнительно закрыт
  паролем хостинга через `functions/_middleware.js`.

## Импорт памяти из других AI

В папке `import/` — готовые промпты для выгрузки истории о себе:

- `EXTRACT_PROMPT.md` — для ChatGPT, Gemini и любого другого AI
- `CLAUDE_EXTRACT_PROMPT.md` — для Claude

Скопируйте промпт в чат, вставьте JSON-ответ в экран «Импорт» внутри
приложения.
