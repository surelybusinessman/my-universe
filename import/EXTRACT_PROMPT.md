# Промпт для выгрузки памяти о себе

Скопируйте всё, что ниже черты, и отправьте в чат с ChatGPT, Gemini, Perplexity или
любым другим AI, где накопилась история общения с вами. Скопируйте ответ целиком
(это будет JSON) и вставьте его в экран «Импорт» в «Моей Вселенной».

---

Ты — ассистент, который помогает мне восстановить историю моих собственных
достижений, навыков, целей и незавершённых дел на основе всего, что ты помнишь
обо мне из нашего общения (истории чатов, если у тебя есть к ней доступ, или
из текущего разговора).

Правила:
1. Ничего не выдумывай. Включай только то, что реально обсуждалось. Если
   неуверен — пометь `"confidence": "low"`.
2. Разложи всё по категориям: достижения (`achievement`), навыки (`skill`),
   цели (`goal`), обучение в процессе (`learning`), то, что не получилось или
   было заброшено (`failure`).
3. Сгруппируй по смысловым сферам жизни (карьера, здоровье, творчество,
   отношения, финансы, языки — любые, какие подходят) — это и есть «галактики».
4. Ответь СТРОГО в виде JSON без каких-либо пояснений до или после — только
   сам JSON, потому что он будет вставлен в программу как есть.

Формат ответа:

```json
{
  "galaxies": [
    { "title": { "ru": "Карьера", "en": "Career" }, "color": "#4FC3F7" }
  ],
  "nodes": [
    {
      "galaxy": "Карьера",
      "type": "achievement",
      "title": { "ru": "Название на русском", "en": "Title in English" },
      "description": { "ru": "Краткое описание", "en": "Short description" },
      "startedAt": "2023-05",
      "completedAt": "2023-11",
      "progress": 100,
      "level": 3,
      "status": "done",
      "tags": ["тег1", "тег2"],
      "confidence": "high"
    }
  ]
}
```

Пояснения к полям:
- `galaxy` — название сферы жизни, должно совпадать с одним из `galaxies[].title.ru`
  или `.en` дословно.
- `type` — одно из: `achievement`, `skill`, `goal`, `learning`, `failure`.
- `status` — одно из: `done`, `in_progress`, `planned`, `abandoned`.
- `progress` — число 0-100, насколько это сделано, по твоей оценке.
- `level` — число 1-5, насколько это крупная/значимая единица (1 — мелочь,
  5 — веха).
- `startedAt` / `completedAt` — в формате `"YYYY-MM"` или `"YYYY"`, либо `null`,
  если неизвестно.
- `confidence` — `"high"`, `"medium"` или `"low"`: насколько ты уверен, что это
  было на самом деле, а не додумано.

Пройдись по всей нашей истории общения максимально широко: работа, учёба,
навыки, которые я упоминал, планы, о которых говорил, трудности, увлечения,
привычки, языки, спорт, творчество — всё, что относится к моей жизни и
развитию. Верни от 10 до 100 записей, в зависимости от того, сколько
реально есть материала — не растягивай искусственно и не выдумывай для
объёма.
