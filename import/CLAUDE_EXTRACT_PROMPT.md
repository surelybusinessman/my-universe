# Промпт для выгрузки памяти о себе — для Claude

Используйте это в любой сессии Claude (Claude.ai, Claude Code, проектная память),
где накопился контекст о вас. Скопируйте ответ (JSON) и вставьте в экран
«Импорт» в «Моей Вселенной», выбрав источник «Claude».

---

Просмотри всё, что ты знаешь обо мне — из памяти проекта, из истории этого
разговора, из сохранённых заметок о пользователе (если они у тебя есть) —
и собери из этого структурированную сводку моих достижений, навыков, целей
и незавершённых дел.

Правила:
1. Ничего не выдумывай. Только то, что реально было озвучено или видно из
   контекста. При сомнении ставь `"confidence": "low"`.
2. Категории: `achievement` (достижение), `skill` (навык), `goal` (цель),
   `learning` (обучение в процессе), `failure` (не получилось / брошено).
3. Сгруппируй по сферам жизни (галактикам) — например, работа, конкретные
   проекты, технические навыки, личное развитие.
4. Ответь СТРОГО JSON без пояснений вокруг — он будет вставлен в программу
   как есть.

Формат ответа — тот же, что и для других AI:

```json
{
  "galaxies": [
    { "title": { "ru": "Работа", "en": "Work" }, "color": "#4FC3F7" }
  ],
  "nodes": [
    {
      "galaxy": "Работа",
      "type": "achievement",
      "title": { "ru": "Название на русском", "en": "Title in English" },
      "description": { "ru": "Краткое описание", "en": "Short description" },
      "startedAt": "2024-01",
      "completedAt": null,
      "progress": 60,
      "level": 3,
      "status": "in_progress",
      "tags": ["проект"],
      "confidence": "medium"
    }
  ]
}
```

Поля те же, что в общем промпте: `type` ∈ {achievement, skill, goal, learning,
failure}; `status` ∈ {done, in_progress, planned, abandoned}; `progress` — 0-100;
`level` — 1-5; `confidence` — high/medium/low.

Если у тебя нет доступа к истории за пределами текущего разговора — так и
скажи в начале своего ответа обычным текстом, а затем всё равно верни JSON
на основе того, что видно из этого разговора (даже если это будет короткий
список).
