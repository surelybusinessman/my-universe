# Перенос на другое устройство и резервные копии

## Главное, что нужно понять

В этой папке лежит **только код**. Ваших записей здесь нет и никогда не будет —
это сделано намеренно, чтобы личные данные не попали в GitHub.

Ваши 45 записей хранятся **зашифрованными в браузере** того компьютера, где вы
их создали (технически — в хранилище IndexedDB). Ни на сервере Cloudflare, ни в
репозитории, ни у кого-либо ещё их нет.

Отсюда следует важное: **скопировать папку на другой компьютер недостаточно** —
данные так не переедут. Для них есть отдельный механизм.

## Перенос вселенной на другое устройство

Сам сайт переносить не нужно — он уже в интернете и открывается откуда угодно.
Переносить нужно только данные, одним файлом.

**На старом устройстве:**

1. Откройте https://my-universe-6i8.pages.dev и войдите
2. Нажмите кнопку **«Копия»** в правом верхнем углу
3. Скачается файл вида `my-universe-backup-2026-08-09.json`

**На новом устройстве:**

1. Откройте тот же адрес https://my-universe-6i8.pages.dev
2. Введите пароль хостинга (окно браузера до загрузки сайта)
3. На экране входа внизу — **«Перенос с другого устройства»**, выберите
   скачанный файл
4. Введите свой пароль приложения — вселенная на месте, со всеми записями

Файл копии передавайте как угодно: почта, мессенджер, флешка, облако. Он
зашифрован тем же паролем, что и оригинал — без пароля это нечитаемый набор
байт, даже если файл попадёт к посторонним.

## Резервные копии

Данные живут в браузере, а значит уязвимы к обычным бытовым вещам:

- очистка «данных сайтов» или истории браузера сотрёт вселенную;
- переустановка системы или смена браузера — то же самое;
- поломка диска.

Поэтому раз в пару недель нажимайте **«Копия»** и складывайте файл туда, где он
переживёт компьютер: облако, второй диск, почта самому себе.

**Потеря пароля равна потере данных.** Восстановления «через поддержку» не
существует — шифрование настоящее. Единственная страховка, кроме пароля, — код
восстановления, который показывался один раз при создании вселенной. Если он
не сохранён, сохраните хотя бы бэкап-файл и пароль в разных местах.

## Перенос самой разработки (если захотите дорабатывать проект)

Код лежит на GitHub, поэтому папку копировать тоже не обязательно:

```bash
git clone https://github.com/surelybusinessman/my-universe.git
cd my-universe
npm install
npm run dev
```

Понадобится Node.js и Git. Папку `node_modules` копировать не нужно — она
собирается из `package.json` командой `npm install` и весит сотни мегабайт.

Если всё же копируете папку целиком (например, на флешке без интернета) —
скопируйте всё, **кроме** `node_modules` и `dist`: обе восстанавливаются
командами `npm install` и `npm run build`.

## Что где лежит в проекте

| Путь | Что это |
|---|---|
| `src/crypto/vault.js` | Шифрование: PBKDF2 + AES-256-GCM, код восстановления |
| `src/data/store.js` | Хранение зашифрованного контейнера в браузере |
| `src/data/backup.js` | Скачивание и чтение файлов резервных копий |
| `src/data/sync.js` | Синхронизация контейнера между устройствами через `functions/api/vault.js` |
| `functions/api/vault.js` | Серверная часть синхронизации: GET/PUT в Cloudflare KV |
| `src/data/schema.js` | Структура данных: галактики, звёзды, связи |
| `src/data/mutations.js` | Добавление, изменение и удаление записей |
| `src/auth/LockScreen.jsx` | Вход, создание пароля, восстановление |
| `src/scene/` | 3D-сцена: галактики, звёзды, связи, камера |
| `src/editor/` | Формы редактирования галактик и звёзд |
| `src/analytics/` | Проценты, счётчики, хронология |
| `src/import/` | Импорт из других AI, поиск дублей и отсев мусора |
| `functions/_middleware.js` | Пароль хостинга на Cloudflare |
