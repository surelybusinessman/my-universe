# Моя Вселенная — перенос на другой компьютер

Скопируйте **всю эту папку целиком** на флешку или в облако, перенесите на
новый компьютер — и следуйте одному из двух путей ниже.

## Что внутри

| | |
|---|---|
| `my-universe/` | Весь код проекта вместе с историей изменений |
| `КОПИЯ-ДАННЫХ/` | Сюда кладётся файл с вашими записями |
| `Запустить-на-новом-ПК.ps1` | Установит всё нужное и запустит проект |

Папки `node_modules` здесь нет намеренно — она весит 220 МБ и собирается
заново одной командой. Поэтому весь пакет занимает меньше мегабайта.

---

## Перед переносом: заберите свои данные

**Это обязательный шаг.** Записи не лежат в этой папке — они хранятся
зашифрованными внутри браузера того компьютера, где вы их создавали.

1. Откройте https://my-universe-6i8.pages.dev и войдите
2. Нажмите кнопку **«Копия»** в правом верхнем углу
3. Скачается файл вида `my-universe-backup-2026-08-10.json`
4. Положите этот файл в папку **`КОПИЯ-ДАННЫХ`**

Файл зашифрован вашим паролем. Даже если он попадёт к посторонним, без пароля
это нечитаемый набор символов — можно спокойно нести на флешке или слать почтой.

---

## Путь 1: просто пользоваться (проще)

Разворачивать проект не нужно вообще — сайт уже работает в интернете.

1. На новом компьютере откройте https://my-universe-6i8.pages.dev
2. Браузер спросит логин и пароль хостинга — введите их
3. На экране входа внизу нажмите **«Перенос с другого устройства»**
4. Выберите файл из папки `КОПИЯ-ДАННЫХ`
5. Введите свой пароль приложения

Всё. Вселенная на месте, со всеми записями.

## Путь 2: запустить проект локально (если хотите дорабатывать)

1. Правой кнопкой по **`Запустить-на-новом-ПК.ps1`** → «Выполнить с помощью
   PowerShell»
2. Скрипт сам проверит и при необходимости поставит Node.js, соберёт
   зависимости и откроет браузер
3. Дальше те же шаги 3–5 из первого пути

Если Windows ругается на запуск скриптов, откройте PowerShell и выполните:

```powershell
Set-ExecutionPolicy -Scope Process -Bypass
```

потом запустите скрипт снова.

## Про один клик, который нельзя автоматизировать

Файл копии приходится выбирать вручную. Это не недоработка: браузеры намеренно
запрещают внешним программам писать в своё хранилище — иначе любая программа на
компьютере могла бы залезть в данные ваших сайтов. Поэтому последний шаг всегда
делает человек.

## Два разных пароля — не перепутайте

**Пароль хостинга** — окно браузера, которое появляется *до* загрузки сайта.
Общий для всех устройств, защищает адрес от посторонних.

**Пароль приложения** — экран «Вход в вашу вселенную» *внутри* сайта. Им
зашифрованы сами данные. Его не знает никто, кроме вас, и восстановить его
невозможно — только через код восстановления, который показывался один раз при
создании вселенной.

## Не потеряйте данные

Записи живут в браузере, а значит исчезнут, если:

- почистить «данные сайтов» или историю браузера;
- переустановить систему или сменить браузер;
- сломается диск.

Нажимайте **«Копия»** раз в пару недель и держите файл там, где он переживёт
компьютер. Пароль и файл копии храните в разных местах.
